# 📊 Excel – CPI Inflation Case Study

## 📌 Project Overview

This project analyzes **Consumer Price Index (CPI) inflation data for India using Microsoft Excel** to understand inflation trends, category-level changes, and pre- vs post-COVID patterns.

The project focuses on transforming raw CPI data into meaningful analysis and business-friendly visualizations.

---

## 🎯 Business Objective

The objective is to:

- Analyze CPI trends over time
- Compare inflation patterns across periods
- Understand category-wise inflation movement
- Identify major changes in consumer prices
- Present findings through Excel-based visualizations and dashboards

---

## 🛠️ Tools & Excel Skills

- **Microsoft Excel**
- Data Cleaning & Formatting
- Excel Formulas
- Pivot Tables
- Pivot Charts
- Dashboard Development
- Data Validation
- Trend Analysis
- Comparative Analysis

---

## 📊 Key Analysis

### 1. CPI Trend Analysis
Analyze how CPI values change over time and identify major upward or downward movements.

### 2. Inflation Rate Comparison
Compare inflation behavior across different periods to identify changes in price levels.

### 3. Pre-COVID vs Post-COVID Analysis
Compare CPI patterns across the selected pre-COVID and post-COVID periods to understand how inflation changed.

### 4. Category-wise Analysis
Analyze inflation-related categories to identify which categories experienced larger changes.

### 5. Data Visualization
Use charts and dashboard elements to communicate trends and comparisons clearly.

---

## 💡 Key Insights

- CPI trends were analyzed across multiple time periods.
- Inflation patterns were compared to identify changes in price levels.
- Category-level analysis helps identify areas experiencing stronger price movements.
- Visual analysis makes major trends and fluctuations easier to interpret.

> **Note:** Detailed numerical findings should be interpreted directly from the Excel workbook and dashboard.
