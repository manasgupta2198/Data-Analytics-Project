# CPI Inflation Analysis Project

## Project Overview
This project analyzes CPI (Consumer Price Index) inflation data using Excel to understand inflation trends and price changes over time.

## Objective
The main objective of this project is to analyze inflation patterns and identify changes in CPI values across different periods.

## Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Excel Formulas
- Data Cleaning

## Key Analysis
- CPI Trend Analysis
- Inflation Rate Comparison
- Data Cleaning and Formatting
- Chart and Visualization

## Dataset
The dataset contains CPI inflation-related data used for analysis and visualization.

## Key Insights
- Inflation trends were analyzed over time.
- CPI value changes were compared.
- Visual charts helped identify patterns and fluctuations.

## Project Files
- Excel Dataset (.xlsx)
- Dashboard/Charts
- Analysis File

## Conclusion
This project helps understand inflation behavior and supports data-driven analysis using Excel.
